`google-bracket.svg` is the unmodified community mark downloaded from
[Google for Developers](https://developers.google.com/static/assets/img/icons/google-bracket.svg).
`Chevrons.tsx` uses its exact path data and the theme tint combinations recorded
in `GDGoC_IBA_Instructions.txt`. This is a mark, not a chapter logo lockup.

The repository now contains `GDG Brand Kit.pdf`. Pages 15–16 link to the
official [horizontal templates](https://drive.google.com/drive/folders/1QAS6FgU7BmtBPMNvM1k2ONjYU6EiDJsL)
and [stacked templates](https://drive.google.com/drive/folders/10sNJZ9rKdE5x5fuxinq3aUdEQ1brBSro).
The chapter lockups reuse the template's original embedded artwork, unchanged,
and add “Institute of Business Administration” using outlines from the supplied
Google Sans font. The mark, colours, headline and proportions are not redrawn.
