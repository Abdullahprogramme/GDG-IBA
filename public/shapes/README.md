# SVG artwork exports

These standalone SVGs are blue-colourway exports of the reviewed React shape
components. They preserve the SVG aspect ratio and use non-scaling ink strokes.
Use the React components for inherited themes or alternate colourways.

`sample-frame.svg` is explicitly labelled geometric sample artwork for testing
photo and avatar frames. Replace it with consented chapter photos in page work.

The chevron paths come from Google's official community mark; provenance is
recorded in `public/brand/README.md`. The other shapes follow the P1–P7
specifications in `GDGoC_IBA_Instructions.txt`. The original kit comparison
remains pending because its PDF is not in the repository.
